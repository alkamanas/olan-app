# Contributing

This repository is a **read-only mirror**. It is generated from Olan's internal repository, where
the Olan Apps packages are developed together with the Olan server, and every push here replaces
the previous contents.

- **Issues are welcome**: bug reports, documentation fixes, questions and feature requests at
  https://github.com/alkamanas/olan-app/issues. Include the package versions
  (`npx olan-app --version`), Node.js version and a minimal `olan-app.json` / snippet when you can.
- **Pull requests** cannot be merged directly, because the next sync would overwrite them. Small
  fixes are still useful as a description of the change: we apply them in the internal repository
  and they appear here with the next sync.
- **Security issues**: please do not open a public issue; report them privately through GitHub's
  "Report a vulnerability" (Security tab of this repository).
